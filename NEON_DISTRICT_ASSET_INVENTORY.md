# NEON DISTRICT — Asset Inventory & Licensing (Phase A)

## Strategy
**No external downloads.** The environment is generated procedurally into Phaser canvas textures at scene-create time (same proven pattern as the current `facilityArt.ts` / `pixelArt.ts`). This keeps licensing trivially clean (all original, generated in-repo) and avoids texture-size/loading risk.

The three attached reference images (`image_5c00bd`, `image_cb7961`, `image_ab90de` in the composer-images dir) are **style references only — they are NOT embedded, shipped, or traced**. All generated art is original code-drawn shapes in the reference palette.

Seeded PRNG (`mulberry32`-style) so every reload/test run renders identical art — required for screenshot-stable QA.

## Sizes / performance budget
- Layer textures: width = chapter width (≤1500), height ≤ groundY (560) — same as current layers.
- Rain/fog tiles: 256×256, tiled. Vehicles/glow: ≤64×64. Signs: per-object small canvases as today.
- No texture larger than 1536×576; no runtime canvas redraws except ≤6 window flips/sec.
